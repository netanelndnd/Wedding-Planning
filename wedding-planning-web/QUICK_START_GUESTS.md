# 👥 מדריך מהיר - ניהול אורחים עם Excel

## 🚀 התחלה מהירה (3 שלבים פשוטים!)

### 📍 איך להגיע לדף האורחים?

**אפשרות 1: דרך הדשבורד**
```
http://localhost:3000/dashboard
↓
לחץ על כרטיס "👥 אורחים"
```

**אפשרות 2: ישירות**
```
http://localhost:3000/guests
```

---

## 📥 שלב 1: הורדת תבנית Excel

### מה תקבל?
- ✅ קובץ Excel מוכן עם כל השדות
- ✅ דף "הוראות" עם הסברים מפורטים
- ✅ שורת דוגמה למילוי
- ✅ עיצוב מקצועי וקריא

### איך?
1. היכנס ל-http://localhost:3000/guests
2. לחץ על **"📥 הורד תבנית Excel"**
3. הקובץ יורד עם השם: `רשימת_אורחים_[שמות].xlsx`

---

## ✍️ שלב 2: מילוי הטופס

### פתח את הקובץ ב:
- 📗 Microsoft Excel
- 📊 Google Sheets
- 📋 LibreOffice Calc
- 🍎 Numbers (Mac)

### שדות למילוי:

| שדה | תיאור | חובה? | דוגמה |
|-----|-------|-------|-------|
| **שם מלא** | שם האורח | ✅ | ישראל ישראלי |
| **טלפון** | מספר טלפון | ❌ | 050-1234567 |
| **אימייל** | כתובת מייל | ❌ | israel@example.com |
| **צד** | צד א / צד ב / משותף | ✅ | צד א |
| **הוזמן** | כן / לא | ✅ | כן |
| **אישר הגעה** | כן / לא / ריק | ❌ | כן |
| **מספר אורחים** | כולל האורח עצמו | ✅ | 2 |
| **שולחן** | מספר שולחן | ❌ | 1 |
| **הערות** | הערות כלליות | ❌ | צמחוני |

### 💡 טיפים חשובים:
- ❌ **אל תמחק** את שורת הכותרות (השורה הראשונה)
- ✂️ **אפשר למחוק** את שורת הדוגמה
- 📋 **אפשר להעתיק** שורות קיימות ולשנות את הפרטים
- 📝 **שורות ריקות** יתעלמו אוטומטית

## 📤 שלב 3: העלאה למערכת

### איך מעלים?
1. שמור את הקובץ (Ctrl + S)
2. חזור ל-http://localhost:3000/guests
3. לחץ על **"📤 העלה קובץ Excel"**
4. בחר את הקובץ שמילאת
5. ✨ **בום!** הנתונים יייבאו אוטומטית

### מה קורה אחרי ההעלאה?
- ✅ הודעת הצלחה בירוק
- 📊 תצוגה מקדימה של כל האורחים
- 🎨 טבלה מעוצבת עם צבעים
- 📈 ספירת אורחים

## ⚠️ פתרון בעיות נפוצות

### הקובץ לא מתקבל?
- ✅ ודא שהקובץ הוא `.xlsx` או `.xls`
- ✅ בדוק שלא מחקת את שורת הכותרות
- ✅ ודא שיש לפחות שם אחד בעמודת "שם מלא"

### שגיאת "שגיאה בקריאת הקובץ"?
- ✅ נסה לפתוח את הקובץ ב-Excel ולשמור מחדש
- ✅ ודא שהקובץ לא פגום
- ✅ נסה להוריד תבנית חדשה

### הנתונים לא נכונים?
- ✅ ודא שמילאת בפורמט הנכון:
  - **צד**: רק "צד א" / "צד ב" / "משותף"
  - **הוזמן**: רק "כן" / "לא"
  - **אישר הגעה**: רק "כן" / "לא" / ריק
  - **מספר אורחים**: מספר שלם בלבד

## 🎯 דוגמת תרחיש מלא

### תרחיש: לחתונה של דוד ושרה יש 50 אורחים

#### יום 1: הכנה
```
1. דוד נכנס לדשבורד → לוחץ על "אורחים"
2. מוריד תבנית Excel
3. מעביר את הקובץ לשרה במייל
```

#### יום 2: מילוי
```
4. שרה פותחת את הקובץ ב-Excel
5. קוראת את דף "הוראות"
6. ממלאת 30 אורחים מצד המשפחה שלה
7. מעבירה את הקובץ לדוד
```

#### יום 3: השלמה
```
8. דוד ממשיך מהשורה 31
9. ממלא 20 אורחים נוספים מצידו
10. שומר את הקובץ
```

#### יום 4: העלאה
```
11. דוד חוזר למערכת
12. מעלה את הקובץ
13. רואה 50 אורחים בטבלה המעוצבת
14. מוודא שהכל נכון
15. ✅ מוכן!
```
