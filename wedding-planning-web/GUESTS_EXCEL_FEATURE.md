# תכונת ייצוא/ייבוא Excel לאורחים 📊

## תיאור
תכונה מתקדמת לניהול רשימת אורחים באמצעות קבצי Excel. מאפשרת למשתמשים להוריד תבנית Excel, למלא אותה, ולהעלות אותה חזרה למערכת.

---

## 🎯 תכונות

### 1. **הורדת תבנית Excel**
- קובץ Excel מוכן עם כל השדות הנדרשים
- כולל דף "הוראות" מפורט עם הסברים ודוגמאות
- עיצוב מקצועי עם רוחבי עמודות אופטימליים

### 2. **העלאה וייבוא**
- קריאה אוטומטית של קובץ Excel
- המרה אוטומטית של נתונים לפורמט המערכת
- בדיקות תקינות ושגיאות מפורטות

### 3. **תצוגה מקדימה**
- טבלה מעוצבת עם כל האורחים שיובאו
- סיווג לפי צדדים (צד א, צד ב, משותף)
- סטטוס אישור הגעה בצבעים

## 🚀 איך להשתמש?

### שלב 1: הורדת תבנית
1. היכנס לדף "אורחים" מהדשבורד
2. לחץ על **"📥 הורד תבנית Excel"**
3. הקובץ יורד אוטומטית למחשב

### שלב 2: מילוי הטופס
1. פתח את הקובץ ב-Excel / Google Sheets
2. קרא את דף "הוראות" להסברים מפורטים
3. מלא את פרטי האורחים בדף "אורחים"
4. שמור את הקובץ

### שלב 3: העלאה למערכת
1. חזור לדף "אורחים" במערכת
2. לחץ על **"📤 העלה קובץ Excel"**
3. בחר את הקובץ שמילאת
4. המערכת תייבא אוטומטית את כל הנתונים
